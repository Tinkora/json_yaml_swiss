# Maturity

[简体中文](MATURITY.zh-CN.md)

JSON YAML Swiss is **Draft** until hosted checks and the deployed application
provide evidence for the exact public commit. Do not add a maturity badge before
that evidence exists.

| Level | Minimum evidence |
| --- | --- |
| Draft | Scope, trust boundary, and representative local behavior are documented. |
| Alpha | Native, WASM, browser, documentation, dependency, and security checks pass in hosted CI; Pages is verified. |
| Beta | Alpha evidence remains current; public interfaces are stable and non-maintainer use has completed a feedback and remediation cycle. |
| Stable | Beta evidence spans compatible releases; support lifecycle, two trusted release reviewers, and protected publishing controls are evidenced. |

The current product is human-usable through a local browser UI. Machine-readable
reports do not imply an agent transport or hosted API.
