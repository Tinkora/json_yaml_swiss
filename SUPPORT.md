# Support

[简体中文](SUPPORT.zh-CN.md)

JSON YAML Swiss is a local utility, not a hosted conversion service.

For a reproducible bug, open a GitHub issue after the repository is public.
Include the smallest non-sensitive input, exact browser steps, commit or
version, operating system, browser version, and observed versus expected
behavior.

Use GitHub Discussions for questions and narrowly scoped feature proposals.
Explain the user pain and why existing tools do not solve it. Do not post
secrets, private configuration, credentials, or vulnerability details. Follow
[SECURITY.md](SECURITY.md) for security reports.
